About me

Soy Ingeniero de Sistemas de Barranquilla, Colombia. Como Full Stack Developer, construyo soluciones web, móviles y de escritorio con foco en rendimiento, UX y código mantenible. Trabajo principalmente con React, Next.js, React Native, Node.js/Express y MySQL; domino HTML, CSS, JavaScript y el control de versiones con Git/GitHub.

He desarrollado proyectos reales: un sistema de inventario de escritorio para droguerías, un clon de Google Traductor en React + TypeScript usando la API de OpenAI, una herramienta Image to Code que transforma diseños en HTML/CSS/JS, mi portafolio personal y landing pages como Plomería Indira. Me gusta entregar productos listos para producción, bien documentados y fáciles de mantener.

Aprendo con lógica y práctica, y disfruto convertir ideas en productos funcionales. Si buscas alguien que se ponga la camiseta y lleve tu proyecto de 0 a deploy, hablemos.
